import { Aside } from '@astrojs/starlight/components';

La API alojada (`https://api.axiomic.cl`) corre en modo de prueba. Para usarla necesitas una llave
`axk_test_…` de un comercio de prueba, que hoy entregamos a mano mientras construimos el panel.

Escríbenos a [contact@axiomic.cl](mailto:contact@axiomic.cl?subject=Acceso%20a%20la%20API%20de%20prueba)
con tu nombre, tu empresa y qué quieres construir. Te respondemos con tu llave y las cuotas de tu
comercio de prueba.

<Aside type="note" title="Pronto, un formulario">
Aquí habrá un formulario para pedir la llave sin escribir un correo. No pidas acceso con datos de
tus clientes: el modo de prueba usa sólo datos sintéticos.
</Aside>

Con tu llave, sigue el [Quickstart](/empezar/quickstart/).
