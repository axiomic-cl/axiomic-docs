## Un cobro, en una llamada

```sh
curl -s -X POST https://api.axiomic.cl/v1/payment_intents \
  -H "Authorization: Bearer $AXIOMIC_KEY" \
  -H "Idempotency-Key: pedido-1042" \
  -H "Content-Type: application/json" \
  -d '{"amount_clp": 34990, "reference": "pedido-1042"}'
```

La respuesta trae el `pay_url` de la página de pago y el monto exacto que transfiere tu cliente.
Cuando el abono llega, recibes `payment_intent.paid` firmado y un recibo que cualquiera puede
verificar.

<Aside type="note" title="Modo de prueba">
Hoy la API corre con un banco simulado y datos sintéticos: ningún peso real se mueve.
</Aside>
